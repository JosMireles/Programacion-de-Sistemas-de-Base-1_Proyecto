Descripcion del Lenguaje:

 El proyecto implementa un lenguaje sencillo orientado al procesamiento de oraciones en
 español, con soporte para enunciados declarativos, interrogativos y exclamativos.
 Su propósito es demostrar el funcionamiento de un analizador léxico y sintáctico,
 identificando tokens, validando la estructura gramatical de la entrada y permitiendo
 posteriormente su conversión a voz mediante un módulo TTS.

 El lenguaje reconoce elementos como palabras, números, signos de puntuación, signos de
 interrogación y signos de admiración, siguiendo las reglas definidas en la gramática
 EaV2.g4.

 Ejemplo:
 Hola Profesor, ¿cómo está?
 Estoy probando el proyecto.
 ¡Qué buena práctica!
